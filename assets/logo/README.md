# constellation - logo

Palette: **ink + platinum** (no gold). Wordmark: **Spectral** (embedded in the SVGs).

Use the `-ink` files on light backgrounds; the others are built for dark backgrounds.

## Compositions
| File | Use |
|---|---|
| `constellation-lockup.svg` / `.png` | horizontal lockup (emblem + wordmark), primary |
| `constellation-lockup-ink.svg` / `.png` | horizontal lockup, for light backgrounds |
| `constellation-stacked.svg` / `.png` | stacked lockup |
| `constellation-stacked-ink.svg` / `.png` | stacked, light backgrounds |
| `constellation-wordmark.svg` / `.png` | wordmark only |
| `constellation-wordmark-ink.svg` / `.png` | wordmark, light backgrounds |
| `constellation-emblem.svg` / `-512.png` | emblem only |
| `constellation-emblem-ink.svg` / `-512.png` | emblem, light backgrounds |
| `constellation-banner-dark.png` | 1600x500 README banner (dark) |
| `constellation-banner-light.png` | 1600x500 README banner (light) |
| `constellation-favicon.svg` / `-256/64/32.png` | favicon (simplified mark on tile) |
| `constellation-favicon-transparent.svg` | favicon mark, transparent |
| `constellation-favicon-ink.svg` | favicon mark, ink (light bg) |

The SVGs are scalable and self-contained: the wordmark font is embedded, so they render correctly anywhere (browser, Figma, README) without installing Spectral.
